### Daily Congressional Record

Parsing the daily Congressional Record relies on the repository [congressional-record](https://github.com/unitedstates/congressional-record). This is noted under `source/lib/requirements.txt`. However, one may run into conflicting requirements with other packages when using this repository. For this reason, it is recommended to set up a Python virtual environment (venv) that specifically handles this step of the process.

The file `datastore/congressional_record.zip` is an archived version of the repository as of March 9, 2026. Modification of the original code is permitted under the [original license](https://github.com/unitedstates/congressional-record/blob/ec0850412acffd0fc2dc6ed79fbd376e4699439d/LICENSE).
